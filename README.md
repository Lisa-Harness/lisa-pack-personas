# lisa-pack-personas

Conversational personas for Lisa: `thinker` (interactive clarification),
`researcher` (web research + synthesis), and `organizer` (durable-state
maintenance).

Use `/organize` or `/organizer` when the intent is to inventory, consolidate,
or safely prune storage, memories, and other durable knowledge artifacts.

Note: `planner` / `explainer` → `lisa-pack-core`
  (sdk core pack — they are kernel workflow front-ends, not personas).

## Install

```powershell
pip install -e .
```

See the parent [`lisa-packs`](https://github.com/Lisa-Harness/lisa-packs)
repo for the submodule promotion lifecycle.
